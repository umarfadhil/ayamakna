# Code Rules

- Use React functional components and hooks.
- Prefer modular, reusable UI components.
- Use absolute imports with `@` alias for `src`.
- Style with Tailwind CSS utility classes.
- Use D3 for graph logic and rendering.
- Store persistent data in localStorage with clear keys.
- Avoid magic values; use constants and enums.
- Keep business logic in store and lib files, UI logic in components.
- Use TypeScript for type safety and interfaces.
- Follow Vite and Tailwind conventions for config files.
- Use React Query for async data management.
- Keep routes and providers in App.tsx.
- Document complex functions and components.
