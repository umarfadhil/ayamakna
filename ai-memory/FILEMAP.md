# Filemap (Critical Files)

1. src/main.tsx - Entry point, renders App
2. src/App.tsx - App root, routing, providers
3. vite.config.ts - Vite build config
4. tailwind.config.ts - Tailwind CSS config
5. src/store/graphStore.ts - Graph data logic, keyword extraction, auto-linking
6. src/lib/utils.ts - Utility functions (class merging)
7. src/components/graph/ForceGraph.tsx - D3 graph visualization
8. src/components/reader/ReadingMode.tsx - Topic reading mode UI
9. src/components/admin/AdminPanel.tsx - Admin topic management UI
10. src/data/quranData.ts - Quranic data definitions

These files form the backbone of the app's structure, logic, and UI.
