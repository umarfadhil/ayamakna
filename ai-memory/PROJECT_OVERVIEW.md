# Project Overview

Ayamakna is a React-based web application designed for interactive exploration and reading of Quranic topics. The project leverages D3 for graph visualization, React Query for data management, and Tailwind CSS for styling. Key features include:
- Force-directed graph for topic navigation
- Reading mode for detailed topic content
- Admin panel for topic management
- Auto-linking and keyword extraction for semantic connections

The app is structured for modularity, with core logic in the `src` directory and UI components organized by function. Vite is used for fast development and build tooling.
